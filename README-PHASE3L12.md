# LittyWatch V5.2 Phase 3L.12 — Bare Plural & Clause Invalidation

Gerichte follow-up op de 6 resterende markt-outliers.

- Mixed-basis items beoordelen hun eigen eerste clause vóór komma/semicolon.
- `gott 2e, materials 2k s` wordt daardoor niet meer gered door de tweede geldprijs.
- Kale meervoud-offers `consets 13e` en `lockpicks 100k` leveren geen betrouwbare unitbasis.
- Expliciete `ea`, `stack`, `/stk` en ratio-notatie blijven geldig.
- Singular bare forms blijven ongemoeid.
- Echte outliers zoals `AnA 1e/ea`, `Hero's Strongbox 12a` en `Gold Zaishen Coin 1750e` worden niet weggefilterd.
