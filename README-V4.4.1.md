# LittyWatch V4.4.1 — Review Split View

- De Review Queue blijft op desktop en tablets naast het detailpaneel staan.
- Het detailpaneel is sticky en afzonderlijk scrollbaar.
- De queue heeft een eigen scrollgebied.
- Alleen echte smalle mobiele schermen schakelen naar één kolom.
- Op mobiel springt een geselecteerde regel automatisch naar het detailpaneel.
- De ontbrekende CSS-variabele `--border` is toegevoegd.
