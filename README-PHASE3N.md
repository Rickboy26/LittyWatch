# Phase 3N — GW Market inventory mapper

De Wiki-downloadroute is verwijderd uit de automatische mapper.

GW Market publiceert in zijn open-source repository itemafbeeldingen per categorie. LittyWatch gebruikt deze uitsluitend tijdelijk als herkenningsreferentie in de browser, vergelijkt ze met de lokale Gw.dat fingerprints en slaat alleen de lokale DAT-ID op.
