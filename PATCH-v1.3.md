# LittyWatch v1.3 — standaard betaalmethodes

Deze versie voegt op het dashboard een vast blok met Kamadan-valutaverhoudingen toe:

- Platinum / gold ↔ ecto
- ecto ↔ armbrace
- ecto ↔ Zaishen Key
- ecto ↔ Obsidian Shard

De waarden staan in `config/exchange-rates.php` en kunnen zonder databasewijziging worden aangepast.
Deze fase haalt de koersen nog niet automatisch uit Kamadan; dat volgt later.
