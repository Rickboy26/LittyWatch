# LittyWatch V5.2 — Phase 3C

Market presentation & variant integrity:
- all user-facing market timestamps are formatted in Europe/Amsterdam;
- prices >= 500 ecto prefer armbraces, while preserving ecto equivalence;
- native armbrace offers keep their original armbrace value visible;
- item charts automatically switch their Y-axis to armbraces for high-value markets;
- explicit negative attribute clauses such as `no chann/curses` no longer create false variants;
- compact same-requirement attribute lists such as `BDS q11 dom/air/FC/...` expand into distinct variants.
