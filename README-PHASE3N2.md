# Phase 3N2 — Public GW1 catalogue import

De mislukte image-matcher is niet langer de basis voor itemkennis.

Admin/Knowledge kan nu de publieke GW1 catalogusbestanden uit GW Market in de browser ophalen en in LittyWatch's eigen Knowledge Base importeren.

Geïmporteerd:
- itemnaam
- categorie
- groeps/type-informatie
- beschikbare stats/metadata
- genormaliseerde aliases

Niet geïmporteerd:
- prijzen/trades; LittyWatch gebruikt daarvoor uitsluitend de eigen Kamadan collector.
- services/giveaways/changelog.
