# LittyWatch V4.3 — Parser Review & Learning

De bestaande `/parser-review` is uitgebreid met:

- aliases die direct door de parser worden gebruikt;
- dynamische service/noise/naamverkoop-uitsluitingen;
- configureerbare setgroottes;
- veel gemiste termen;
- parserkwaliteitsstatistieken;
- correctiehistorie;
- correcties die zonder code-update de volgende parser-run beïnvloeden.

Nieuwe tabellen worden automatisch aangemaakt: `parser_aliases`, `parser_exclusions`, `parser_set_sizes`, `parser_corrections`.
