# LittyWatch V2.6 — Command Center & Global Search

## Nieuwe onderdelen

- `/v2-hub.php` — centraal V2-dashboard
- `/api/v2-search.php?q=...` — globale zoek-API
- `GlobalSearchService` — zoekt in:
  - marktvarianten
  - items
  - traders
  - actieve structured offers

## Command Center

Het nieuwe overzicht combineert:

- systeemtellers
- globale zoekfunctie
- beste actuele deals
- watchlist
- recente alert-events
- navigatie naar alle V2-modules

## Installatie

Er is geen database-installatie nodig.

Open na deployment:

`/v2-hub.php`

Voorbeeld API:

`/api/v2-search.php?q=BDS`
