# LittyWatch V5.2 — Phase 2N Specificity & Confidence Promotion

Phase 2N targets the remaining `low_confidence` review layer after Phase 2M.

- Learned/database generic concepts such as `Miniature`, `Unique item`, `Staff`, `Wand`, `Focus item`, `Bow`, and `Axe` no longer compete in the catalog matcher. Dedicated generic-family recognition remains available for real searches such as `Q8 Bows`.
- Review-level generic shadows are removed after parsing, while accepted generic market variants are preserved.
- Strong established market shorthand is promoted for Ecto, Arms/Armbraces, Polar Bear, Ruby/Sapphire and Soup.
- Concrete catalog identities therefore outrank generic families consistently, including knowledge learned before the taxonomy existed.
